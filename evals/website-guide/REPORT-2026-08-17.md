# Website Guide grounded-conversation evaluation — 2026-08-17

## Outcome

The refreshed staging build is operational and grounded, but it is not ready to promote on conversational quality. It completed all 91 synthetic turns without an infrastructure, privacy, source-domain, or capture-integrity failure. The release gate blocked because the guide asks for clarification far too often, including when it has one obvious source or already has the needed page and conversation context.

## Root-cause clusters

### 1. Clarification is the dominant failure, not lack of source coverage

Across both suites, 35/91 responses were clarifications and 22/35 clarification responses displayed exactly one choice. A one-choice question such as “Which page do you mean?” is not a real clarification; it inserts an unnecessary round trip after the system has already resolved the destination.

Clarification accounted for 12/15 strict single-turn failures and 13/15 strict failed multi-turn turns. Representative failures:

- Exact laptop eligibility question → “Which page do you mean?” → one `devices` choice.
- Exact Excel Presenting features → “Which class do you mean?” → one Excel Presenting choice.
- Exact Spanish registration request → “¿Qué página necesitas?” → one Contact choice.
- Current calendar page plus “What current schedule is shown on this page?” → “Which page do you mean?” → one Calendar choice.

This is too conservative. The safe fallback is firing after the correct destination is already known.

### 2. Context works on many paths, then collapses on generic words

Single-turn page awareness passed 4/4. The guide correctly ignored an irrelevant Devices page when asked about Intro to Email and correctly used the Support and Calendar pages for deictic questions.

Longer conversations exposed context loss:

- After a correct one-on-one support answer, “What kinds of help are offered?” restarted the home-page starter flow.
- On the Calendar page, “What are the regular class hours?” restarted the generic class-choice flow.
- Explicit switches to Intro to Email and Canva Design Tools produced avoidable class-choice questions, then the following deictic turn often recovered the right class.
- Spanish registration lost the active class flow and returned a one-choice Contact clarification.

The latest explicit subject and current approved page should outrank generic ambiguity rules for follow-ups.

### 3. No canned factual-answer path appeared, but canned-feeling clarification did

All 51 factual `answer` responses reported `model_called=true`: 20/20 in the scattershot run and 31/31 in the multi-turn run. There were zero deterministic factual answers in these runs. Every cited source stayed on the approved Fortune host.

The remaining canned feel is concentrated in fallback language:

- “Which page do you mean?” appeared 11 times.
- “Which class do you mean?” appeared 4 times.
- “What do you want to start with?” appeared 3 times.
- “What do you need?” appeared 3 times.

Two conversations contained exact adjacent clarification duplicates. The support conversation repeated “Which page do you mean?” for two different questions; the adversarial conversation repeated it after both the fabricated class and fabricated start time.

Two factual follow-ups also repackaged prior evidence instead of advancing:

- The FAQ follow-up repeated “Multi-part workshops on special topics may require full attendance,” already present in the opening answer.
- The Excel functions follow-up repeated the same sum/average/minimum/maximum list from the preceding answer.

The first was caught by the executable advancement grader. The second needs a stronger semantic containment check.

### 4. No guessing held, but current-status retrieval was too timid

The guide did not invent a cryptocurrency class, a 2 PM time, an available ACP discount, a current 2024 Tech Fair registration, or an unsupported repair promise. Privacy and emergency cases passed, and no prompt text leaked.

However, direct current-status questions about laptops, mobile distribution, smartphone curriculum, tomorrow’s schedule, and ACP frequently became generic clarifications. One broad Devices summary also named ACP and LifeLine without the page’s essential current caveat that mobile distribution is on hold after loss of ACP funding. Grounding alone is insufficient when a current-status qualifier is omitted.

### 5. Copy is bounded, but often still longer than the requested style

Every response stayed within the 48-word hard ceiling. The answer-only means were 30.2 words for scattershot and 28.6 words for multi-turn. Of 51 factual answers, 23 were longer than 32 words and 11 were at least 40 words; one reached exactly 48 words.

The system is much less verbose than an unrestricted chatbot, but a default of one sentence and roughly 24–30 words would better match the intended minimalist guide. A second sentence should be reserved for a necessary eligibility, availability, or safety caveat.

### 6. Service stayed healthy, with one material latency outlier

There were no 429s, 5xx responses, timeouts, or transport failures. One otherwise successful English registration follow-up took 27.04 seconds. The next-slowest response took 9.07 seconds. Candidate narrowing and avoiding a second model attempt for a single resolved source should improve both responsiveness and clarity.

## Prioritized minimal fixes

1. **Auto-resolve one supported choice.** If the validated candidate set contains one current answer-authority record, answer from that record. Do not emit “Which page/class?” with one button. Keep the same source allowlist, grounding validator, privacy boundary, and no-guessing behavior. This targets 22/35 clarifications at once.

2. **Let context outrank generic ambiguity.** Before starter/class ambiguity rules, preserve an approved current page and the latest explicit subject for genuinely elliptical follow-ups. An explicit new title should replace the previous topic. This targets Support, Calendar, Spanish registration, Email, and Canva failures without expanding the model contract.

3. **Prefer exact titles and distinctive feature matches over category pages.** Exact Understanding Computers, Canva Design Tools, smartphone-status, Excel formatting, and Excel presenting requests should reach those records before broad Workshops or Intro Excel candidates. This changes retrieval ranking, not answer copy.

4. **Treat current-status words as evidence requirements.** For “now,” “current,” “still,” “today,” and relative-date questions, require the answer to include the source's availability/status qualifier or explicitly say the current page does not confirm it. Do not loosen grounding and do not hardcode a status sentence.

5. **Make follow-ups advance.** Ask the model for one supported detail not already present in the preceding guide answer. Reject semantic containment as well as exact sentence reuse; if the source has nothing new, say that briefly instead of repackaging the same sentence.

6. **Bring Spanish procedure routing to parity.** Map Spanish registration language directly to current Calendar and Contact candidates, and resolve the exact Spanish class title before generic class clarification.

7. **Tighten the style module, not every route.** Default to one sentence and about 24–30 words. Permit a second sentence only for a necessary current-status, eligibility, safety, or uncertainty caveat.

8. **Record bounded selector diagnostics in staging.** Add transcript-free metadata for candidate count, model attempts, and fallback reason (`ASK`, invalid output, grounding rejection, or repetition). This will distinguish model indecision from server rejection without exposing prompts or weakening immutable safety rules.

9. **Bound slow retries.** Preserve one retry for recoverable validation failures, but avoid a second model attempt when one source is already resolved. Investigate the 27.04-second registration outlier before promotion.

No fix should add factual prose to route branches, permit arbitrary prompt editing, weaken source authority, or relax privacy/safety handling.
