This version makes the operating priority explicit: protect privacy and source
fidelity, answer the latest request directly, then keep the response brief. It
treats the current page as a hint within full-site retrieval, uses current
source metadata when relevant, adapts to non-private constraints supplied by
the participant, and owns mistakes briefly without scripted apologies.

Clarification remains model-authored and is used only when ambiguity blocks a
supported answer. The prompt forbids canned menus, fake invitation questions,
staff impersonation, unsupported external facts, and factual examples embedded
as response templates.
