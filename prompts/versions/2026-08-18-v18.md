# One-or-two-question clarification prompt v18

- Source basis: simplification after live staging clarification evaluation
- Release date: `2026-08-18`
- Behavior release: `model-authored-one-or-two-question-clarification`
- Code-owned policy ID: `2026-08-18-v18`
- Parent policy: `2026-08-18-v17`

This version replaces the single mandatory clarification question with one or
two short, model-authored questions that respond to the participant's words.
It does not add program facts, deterministic participant copy, or a new source
path.

The server continues to own privacy screening, retrieval, allowed source IDs,
grounding, response validation, idempotency, and rate limits. Clarification
remains a reviewed presentation module exposed in Prompts; dashboard proposals
remain non-executable until translated into a named, code-reviewed release.

See `../current.md` for the exact compiled prompt and module boundary. The v17
compiled artifact is preserved in `2026-08-18-v17-compiled.md`.
