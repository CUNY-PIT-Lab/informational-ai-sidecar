# Natural clarification prompt v19

- Source basis: removal of the rigid clarification validator after live model responses were rejected
- Release date: `2026-08-18`
- Behavior release: `model-authored-natural-clarification`
- Code-owned policy ID: `2026-08-18-v19`
- Parent policy: `2026-08-18-v18`

This version gives the model a simple choice: answer naturally from one
relevant approved page when its evidence supports a useful answer, or ask a
brief, natural follow-up when the request or evidence remains ambiguous. It
does not prescribe clarification wording, sentence patterns, or a fixed number
of questions.

The server continues to own privacy screening, retrieval, approved source IDs,
grounding, response validation, idempotency, and rate limits. No factual or
clarification response is hardcoded, and dashboard proposals remain
non-executable until translated into a named, code-reviewed release.

See `../current.md` for the exact compiled prompt and module boundary. The exact
v18 compiled artifact is preserved in `2026-08-18-v18-compiled.md`.
