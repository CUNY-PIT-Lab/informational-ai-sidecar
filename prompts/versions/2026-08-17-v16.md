# Status-faithful grounding prompt v16

- Source basis: live production browser QA after the v15 release
- Release date: `2026-08-17`
- Behavior release: `meeting4-status-faithful-grounding`
- Code-owned policy ID: `2026-08-17-v16`
- Parent policy: `2026-08-17-v15`

This version adds one generic grounding instruction: when an approved record
says a service is on hold, not available, or no longer offered, the guide must
preserve that status and cannot rewrite the service as currently offered or
available. No program facts were added to the prompt, and retrieval, source
authority, grounding validation, and privacy remain server-owned.

When validation catches a draft that reverses a source status, a versioned
retry asks for the negative status first and permits a separate alternative
only when the same approved record explicitly describes it as current.

See `../current.md` for the compiled prompt and module boundary. The immutable
v15 compiled prompt remains in `2026-08-17-v15-compiled.md`.
