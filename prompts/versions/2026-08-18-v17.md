# Model-authored every-safe-turn prompt v17

- Source basis: direct staging reproduction of ordinary Website Guide turns that bypassed the model
- Release date: `2026-08-18`
- Behavior release: `model-authored-every-safe-turn`
- Code-owned policy ID: `2026-08-18-v17`
- Parent policy: `2026-08-17-v16`

This version removes deterministic conversational fallbacks. Every valid,
non-private, non-replayed Website Guide turn must invoke the model. The server
still owns privacy screening, retrieval, allowed source IDs, grounding,
response validation, idempotency, and rate limits; it no longer writes an
answer, handoff, or clarification sentence on the model's behalf.

Vague or unmatched turns receive a bounded set of approved current pages and
must return a single model-authored clarification question. Sensitive requests
receive only the approved Contact record and must return a grounded handoff
without asking for personal details. Missing provider access, exhaustion, or a
twice-rejected model response is an operational error, not a fabricated Guide
turn.

See `../current.md` for the exact compiled prompt and module boundary. The v16
compiled artifact is preserved in `2026-08-17-v16-compiled.md`.
